# Installation Guide

## Prérequis
- **Système d'exploitation**: Windows 10 ou version supérieure, macOS 10.15 ou version supérieure, ou une distribution Linux moderne.
- **Node.js**: Assurez-vous d'avoir Node.js installé, vérifiez en exécutant `node -v` dans le terminal.
- **npm**: Le gestionnaire de paquets Node est nécessaire, il vient généralement avec Node.js.

## Étapes d'installation rapide
1. Clonez le dépôt:
   ```bash
   git clone https://github.com/rebahmoham-ui/ged-archives-desktop.git
   cd ged-archives-desktop
   ```

2. Installez les dépendances:
   ```bash
   npm install
   ```

3. Démarrez l'application:
   ```bash
   npm start
   ```

## Résolution des problèmes
- **Erreur lors de l'installation des dépendances**: Si vous obtenez une erreur lors de l'exécution de `npm install`, assurez-vous que vous avez la bonne version de Node.js.
- **Problèmes de démarrage**: Si l'application ne démarre pas correctement, vérifiez les messages d'erreur dans la console pour plus de détails et assurez-vous que toutes les dépendances sont installées.

## Instructions de configuration
- Une fois l'application lancée, vous pouvez accéder aux paramètres de configuration en naviguant dans le menu de l'application.
- Assurez-vous de configurer vos préférences utilisateur et les paramètres de connexion si applicable.

Pour toute autre question, n'hésitez pas à consulter la documentation ou à ouvrir un problème dans le dépôt.
