# Documentation du Projet

## Fonctionnalités
- Gestion des archives
- Interface utilisateur conviviale
- Fonctionnalités de recherche avancées

## Instructions d'Installation
1. Clonez le dépôt:
   ```bash
   git clone https://github.com/rebahmoham-ui/ged-archives-desktop.git
   ```
2. Accédez au répertoire du projet:
   ```bash
   cd ged-archives-desktop
   ```
3. Installez les dépendances: 
   ```bash
   npm install
   ```

## Guide d'Utilisation
1. Lancez l'application:
   ```bash
   npm start
   ```
2. Accédez à l'interface via `http://localhost:3000`.
